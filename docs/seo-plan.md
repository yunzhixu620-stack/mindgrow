# MindGrow SEO 内容建设

## 已完成的技术底座

- canonical、title/description、Open Graph、Twitter Card；
- SoftwareApplication 与 FAQ 结构化数据；
- `/guide/` 可索引说明页；
- `/robots.txt` 与 `/sitemap.xml`；
- 语义化标题、移动端与可缩放无障碍设置。

## 内容集群

以 `/ai-knowledge-assistant/` 为支柱页，向下建设：

1. 问题词：AI 知识助手是什么、知识库问答如何减少幻觉、RAG 引用如何验证。
2. 场景词：产品研究、会议知识库、客户支持、个人第二大脑、学习复习。
3. 模板词：用户访谈模板、竞品研究模板、会议决策模板、阅读笔记模板。
4. 对比词：MindGrow vs NotebookLM、Notion AI、Glean、Guru；只写可复现的差异。
5. 技术词：混合检索、重排、引用正确率、拒答阈值、知识权限。

## 90 天节奏

- 第 1–2 周：上线 1 个支柱页、5 个场景页、4 个模板页。
- 第 3–6 周：每周 2 篇问题型内容 + 1 个公开评测案例。
- 第 7–10 周：发布 3 个公平对比页、英文首页与 3 个英文场景页。
- 第 11–13 周：根据 Search Console 查询补齐 FAQ、内部链接和低点击标题。

SEO 北极星不是访问量，而是“自然搜索 → 创建第一个知识库”的激活率。辅助指标为有效收录页、非品牌曝光、CTR、首个知识结构完成率和 7 日留存。
