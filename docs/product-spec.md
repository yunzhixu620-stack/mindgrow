# MindGrow V8 产品说明书

## 1. 产品定义

MindGrow 是“可追溯、可编辑、可持续维护”的 AI 知识助手。产品闭环是：资料输入 → 结构化解析 → 来源引用 → 知识导图 → 证据检索 → 回答/拒答 → 反馈与再沉淀。

核心承诺：

1. 结论先绑定证据；证据不足时明确拒答。
2. 用户可以编辑知识结构和回到原文，而不是把结果锁在聊天记录里。
3. 云端用户只需登录和选择工作区，不需要复制 Supabase 登录令牌或工作区令牌。
4. 开发/演示环境保留本地模式；云端生产数据必须经过认证和租户隔离。

## 3. V8 已实现范围

- Supabase 邮箱登录/注册、会话自动续期、工作区创建与切换。
- 阿里云函数验证登录令牌并自动附加/解析 `X-Workspace-Id`；普通用户不接触任何令牌。
- workspaces、members 与所有业务数据的租户字段、后端归属校验、数据库 RLS 和客户端零表权限。
- 会议助手：转写输入、浏览器语音输入、会议摘要、议题、决议、行动项、风险和导图保存。
- 文章解析：公开网页 URL、粘贴正文、最大 15MB PDF；PDF 在浏览器本地提取并保留页码。
- 文章引用：摘要、要点、论点、导图节点绑定逐字引文与段落/页码；保存为 `source_documents` 与 `node_citations`。
- Audio Overview：生成双角色引用脚本；优先调用 CosyVoice 生成 MP3，失败时自动降级为浏览器朗读。
- 知识问答：租户/知识库范围内的候选检索、受限一跳图扩展、来源节点校验、证据不足拒答。
- 可编辑导图、节点引用徽标、回答来源、搜索、折叠、布局、导出、移动端适配。
- 大图渐进展示：14 个及以上节点默认进入主干模式，二级细节折叠为 `＋N`，支持分支聚焦、返回全图和语义缩放。
- API 8.0.0 健康检查、稳定错误码、SSRF 内网拦截、请求超时和大小限制。

## 4. 仍需建设

## 5. 普通用户登录设计

```text
用户输入邮箱/密码
        ↓
Supabase Auth 返回短期 access token（浏览器 SDK 自动保存和刷新）
        ↓
前端请求阿里云 API 时自动携带 Authorization
        ↓
工作区菜单保存 workspace id，并自动加入 X-Workspace-Id
        ↓
阿里云函数验证用户身份和成员关系后访问 Supabase
```

这套封装对普通用户没有令牌门槛。用户只看到“登录、注册、退出、切换工作区”。Supabase publishable key 可以公开，它只用于 Auth；service-role key 与 DashScope key只存在于阿里云函数环境变量中。

## 6. 引用与 Audio Overview 数据链路

```text
URL/正文/PDF
  → 文本清洗或 PDF 本地提取（页码标记）
  → Qwen 生成严格结构：结论 + citationIndexes + 逐字 quote
  → 后端验证 quote 确实存在于原文
  → 页面引用卡片 / 导图引用徽标
  → 保存 source_documents + node_citations
  → Audio 脚本只允许引用已验证 citationIndexes
  → CosyVoice MP3；失败则浏览器双角色朗读
```

## 7. 知识规模增长后的成熟架构

当前 V8 适用于小到中等知识库：Postgres trigram 召回最多 12 个种子节点，再扩展最多 20 个一跳邻居，绝不把整张图塞进模型上下文。下一阶段按以下流水线演进：

1. **采集与版本化**：每个来源保留 `document_id/version/hash/permission/freshness`，增量更新而非全量重建。
2. **结构感知切分**：按标题、段落、表格和页码切分；保存父文档、章节路径、前后邻居和精确字符范围。
3. **双索引**：精确词/稀疏向量保留专有名词，`text-embedding-v4` 处理语义召回；workspace/map/sourceType/time/permission 先过滤。
4. **多路召回**：标题、正文、摘要、实体、图邻居分别 top-k，经 RRF 去重合并 50–100 条候选。
5. **精排**：用 `qwen3-rerank` 选 5–10 条；高风险问题提高阈值，低分直接拒答或追问。
6. **层级摘要**：节点多时按文档/主题生成可失效的摘要索引；摘要负责导航，原始 chunk 负责最终证据。
7. **上下文打包**：优先多样性、去重复、同一论点不堆叠；严格限制 token，并保留引用 ID。
8. **受约束生成**：JSON Schema 输出，逐条 claim 绑定 chunk/citation；无合法引用的 claim 删除或重生成。
9. **答案后验校验**：检查引用存在、权限仍有效、引文支持陈述；失败时降级为证据列表。
10. **质量飞轮**：赞/踩、错误引用、无答案查询进入金标集；每次模型/提示/索引变化必须跑回归。

模型建议基于阿里云当前官方能力：文本检索使用 `text-embedding-v4`（通用建议 1024 维），精排使用 `qwen3-rerank`，结构输出使用 Qwen 非思考模式 JSON output，并继续保留服务端 schema 校验。官方资料：[Embedding](https://help.aliyun.com/en/model-studio/embedding)、[Rerank](https://help.aliyun.com/en/model-studio/rerank)、[Structured output](https://help.aliyun.com/en/model-studio/qwen-structured-output)。
