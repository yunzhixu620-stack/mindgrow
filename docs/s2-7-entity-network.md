# S2.7 Obsidian 式实体网状图验收

日期：2026-07-22
开发底座：`main@6412c95`；API：`10.9.2`

## 结论

S2.7 只改实体图的展示与本地检索，不改实体抽取、数据库、跨库 entity linking 或 GraphRAG 查询路径。

修复前虽然边已经按置信度筛选，但全局图仍渲染全部正式实体，导致无强关系实体占据画布；图内也没有可验收的实体搜索和类型过滤。修复后：

1. 全局默认只显示有引用且置信度不低于 `0.68` 的强关系，每个实体默认最多 3 条强关系；
2. 默认隐藏未进入强关系网络的实体，用户可主动开启“显示无强关系实体”；
3. 点击实体进入一跳关系，保留该实体所有有证据的直接关系；
4. 图内搜索覆盖实体名、别名和解释，点击结果直接进入对应一跳图；
5. 支持按实体类型多选过滤，筛选状态、可见实体数和关系数均在界面明确显示；
6. 悬停继续显示概念说明与专属引用，点击关系继续核对原文证据。

## 验收 Case

| Case | 操作 | 期望 |
|---|---|---|
| EN-01 | 打开实体图 | 默认处于“全局强关系”，无证据、低于阈值的关系不出现 |
| EN-02 | 图中存在孤立正式实体 | 默认不占画布；开启开关后出现，但不伪造弱关系 |
| EN-03 | 点击任一实体 | 只显示该实体和直接一跳邻居 |
| EN-04 | 搜索实体名/别名/解释 | 返回当前正式实体；点击结果进入准确的一跳图 |
| EN-05 | 选择实体类型 | 只保留所选类型实体之间的可用关系；清除后恢复 |
| EN-06 | 筛选导致零强关系 | 显示可解释空状态，可一键查看全部有证据实体 |
| EN-07 | 悬停实体、点击关系 | 分别显示概念说明/引用和关系原文证据 |
| EN-08 | 500 实体本地搜索 | 目标小于 30ms |
