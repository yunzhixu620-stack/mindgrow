## 结论

本任务只修复一个在生产环境稳定复现的问题：从知识宇宙全页返回大型知识库后，初始化竞态会清空“总览”折叠状态，导致 107 个原节点和 1 个展示总览节点同时铺满画布。

以下历史问题在当前生产版本中无法复现，因此本任务不修改对应代码：三板块反复跳转、文章项目卡跳错库、知识宇宙重复抬头、单次展开直接展开全部后代。

## 根因与修复

`MindMapPanel` 已经选择大型图的 `outline` 模式后，父层租户初始化仍可能调用 `resetTenantContext()` 清空共享的 `collapsedNodes`。组件用相同的 large-map key 判断“已经初始化”并提前返回，因此没有恢复被清空的折叠状态。

修复规则：

1. large-map key 首次出现时初始化总览；
2. 同一 key 仍处于 `outline`、但折叠集合被外部清空时恢复总览；
3. 用户主动选择 `all` 或逐级展开后的 `custom` 时不自动折回；
4. 不改变存储节点、边、引用、实体或 GraphRAG 结构。
